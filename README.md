# Site CEDRO Soluções Empresariais

Site estático (HTML + CSS + JS, sem build). Abra `index.html` no navegador ou publique a pasta inteira em qualquer hospedagem (Hostinger, Netlify, Vercel, GitHub Pages).

## Antes de publicar
1. **Contatos provisórios:** edite o topo de `assets/js/main.js` (objeto `CEDRO`): WhatsApp, e-mail e Instagram. O site inteiro se atualiza.
2. **Domínio:** as tags `canonical` usam `https://www.cedrosolucoesempresariais.com.br/`. Troque se o domínio for outro.
3. **Preços:** estão em `solucoes.html`, iguais à tabela "Planos de Licitações".
4. **Política de privacidade:** revise `privacidade.html` com o jurídico (razão social e CNPJ).

## Páginas
index · quem-somos · solucoes (planos e avulsos) · como-atuamos · conteudos + 3 artigos · contato (formulário que abre o WhatsApp) · privacidade · 404
